## 🧩 About

**Left 4 Dead 2 Client** is a comprehensive client modification for Left 4 Dead 2 featuring overlay menu, server browser, custom scripts, mod manager, and performance tweaks.

Based on popular mods like **Silver** and **Left 4 Dead 2 SDK**.

---

## ✨ Features

### 🎮 Core Features
- Overlay Menu — in-game menu for quick access
- Server Browser — find and join custom servers
- Custom Scripts — execute Lua scripts for automation
- Performance Tweaks — optimize FPS and network settings
- Replay System — record and playback gameplay

### 🎨 Cosmetics & Unlocks
- Unlock All — unlock all weapons, skins, and mutations
- Custom Skins — apply custom weapon and character skins
- Mod Manager — easily install and manage addons

### 🏋️ Practice & Training
- Infinite Ammo — unlimited ammunition for practice
- Godmode — invincibility for testing
- Spawn Items — spawn any weapon or item
- No Clip — fly through walls for exploration
